# tutor

Tutor de estudo guiado com IA para qualquer matéria, construído sobre o [Claude Code](https://code.claude.com/docs). Você coloca o seu material numa pasta, abre o Claude Code na raiz do repositório e estuda com um tutor que pede a sua tentativa antes de ajudar, registra seus erros, agenda revisões até a data da prova e retoma de onde parou na sessão seguinte.

> **Estado:** em construção. Este README será completado ao fim do desenvolvimento, com o passo a passo de uso, os requisitos e a demonstração.
