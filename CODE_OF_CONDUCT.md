# Código de conduta

Este projeto quer ser um lugar acolhedor para quem estuda e para quem contribui, sem importar experiência, formação, idade, deficiência, etnia, identidade ou expressão de gênero, orientação sexual, religião, nacionalidade ou aparência.

## O que esperamos

- Respeito nas discussões, inclusive quando houver discordância técnica.
- Críticas dirigidas a ideias e código, nunca a pessoas.
- Paciência com quem está começando.
- Honestidade: reconhecer erros e dar crédito a quem contribuiu.

## O que não aceitamos

- Assédio, insultos, ameaças ou comentários discriminatórios.
- Divulgar dados pessoais de alguém sem permissão.
- Usar o projeto para fraudar avaliações ou distribuir material protegido por direitos autorais.

## Como relatar

Relate problemas de conduta pelo canal privado de contato indicado no perfil do mantenedor no GitHub ou, na falta dele, por uma issue pedindo um canal privado, sem expor os detalhes publicamente. Relatos são tratados com sigilo. Quem violar estas regras pode receber um aviso, ter contribuições removidas ou ser impedido de participar.
